# Changelog

All notable changes to MindRail will be documented in this file.

The project is in `0.x` development and does not yet have a public product release.

## [Unreleased]

### Added

- Development-foundation design and implementation plan.
- Authoritative project index, current-state discipline, system overview, and v0.1 roadmap.
- ADR process plus initial system-boundary and licensing decisions.
- Contribution, security, engineering, agent-workflow, and review standards.
- Root Node.js 24 / pnpm / TypeScript / ESLint / Prettier / Vitest quality configuration.
- Minimal foundation sentinel and smoke test that explicitly do not represent product runtime capability.
- GitHub pull-request and issue templates focused on evidence, architecture impact, and scope control.
- Least-privilege GitHub Actions quality workflow with external actions pinned by immutable commit SHA.

### Changed

- Licensing assumptions were tightened: BUSL-1.1 is used to control production use outside the Additional Use Grant, especially competing hosted/managed use; it is not documented as a blanket prohibition on redistribution.
- Development tooling was aligned with current 2026 stable lines instead of the stale Node 22/pnpm 10 assumptions in the original implementation plan.

### Known limitations

- GitHub-hosted Actions currently fail before runner assignment, so the Node/pnpm quality pipeline has not executed successfully yet.
- `pnpm-lock.yaml` is intentionally absent until it can be generated by a real pinned pnpm toolchain; it has not been fabricated.
