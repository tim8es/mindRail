# Durable Decisions

Record only decisions that future sessions must know and that are not already authoritative elsewhere.

For each decision include:

## YYYY-MM-DD — Decision title

**Decision:** State the durable choice.

**Reason:** State the minimum context needed to understand why it exists.

**Implications:** State constraints this creates for future work.

**Authority:** Link to an ADR, Issue, PR, or other authoritative source when available.

---

Do not record raw reasoning, command transcripts, temporary debugging observations, or per-session summaries here.
