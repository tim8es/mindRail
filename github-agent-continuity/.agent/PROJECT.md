# Project Memory

Keep this file short and stable. Record project truth that a zero-context agent needs before choosing work. Do not use it as a session log.

## Mission

Describe what the project exists to achieve and for whom.

## Product boundaries

- Define what belongs inside the project.
- Define important non-goals or excluded responsibilities.

## Architectural principles

- Record only durable principles that should constrain future implementation.
- Prefer links to authoritative architecture documents when they exist.

## Definition of success

Describe the observable conditions that mean the project has achieved its intended outcome.
