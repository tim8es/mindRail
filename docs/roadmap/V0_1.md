# MindRail v0.1 Roadmap

> **Roadmap only.** Nothing in this file proves that a capability exists. See `docs/CURRENT_STATE.md` for current reality.

The v0.1 objective is a minimal, usable control-plane reference that one maintainer can dogfood with real agents without locking the protocol to a specific vendor.

## Slice 0 — Development foundation

**Status:** implemented and verified on its development branch; repository-level merge enforcement remains tracked separately.

- authoritative repository documentation;
- ADR workflow;
- BSL/source-available licensing foundation;
- agent/contributor workflow;
- TypeScript quality baseline;
- GitHub CI and review templates.

## Slice 1 — Domain contracts

**Status:** implemented and verified on `adr/domain-contracts`; under review in draft PR #4 and not yet merged.

Canonical JSON Schema Draft 2020-12 contracts and generated TypeScript bindings define the smallest stable domain vocabulary:

- Workspace;
- Goal;
- Task;
- Agent;
- Session;
- Lease;
- Checkpoint;
- PermissionRequest / PermissionDecision;
- AuditEvent.

The slice includes strict schema validation, representative positive/negative fixtures, deterministic generated bindings, and generated-drift detection. It does not implement network, database, or cross-record runtime enforcement.

## Slice 2 — Control-plane protocol

**Status:** planned.

Define transport-neutral operations for bootstrap/context retrieval, claiming work, heartbeats, checkpoints, completion/blocking, permission requests, next-action resolution, and human escalation.

## Slice 3 — Local reference runtime

**Status:** planned.

Implement deterministic state transitions, persistence-backed cross-record invariants, lease/revision enforcement, and policy evaluation against a simple local persistence adapter. This provides fast tests before cloud infrastructure enters the system.

## Slice 4 — GitHub integration

**Status:** planned.

Add the first repository/task/config integration without making GitHub a core protocol dependency.

## Slice 5 — Cloudflare reference deployment

**Status:** planned.

Deploy the control plane using Cloudflare Workers and appropriate state primitives behind the same core interfaces. Exact Durable Objects/D1 responsibilities will be decided by ADR after domain/protocol requirements are concrete.

## Slice 6 — Agent integrations

**Status:** planned.

Provide minimal bootstrap/integration paths for:

- Codex;
- ChatGPT-compatible web/app flows where platform capabilities allow it;
- generic MCP clients;
- generic HTTP clients.

The system must tolerate agents whose host platform can interrupt or terminate a session.

## Slice 7 — Human/project projections

**Status:** planned.

Add optional human-facing projections such as Google Sheets or a lightweight UI only after the runtime state model is stable. Projections are not authoritative storage.

## v0.1 success condition

A user can give a goal to a supported agent, the agent can obtain a durable task/context/policy assignment from MindRail, report checkpoints and evidence, continue to the next action without asking the user by default, and escalate only when a policy/decision boundary requires human input.
